# 我的个人网站

这是一个基于 Next.js 构建的个人网站和博客。

## 功能特性

- 响应式设计
- 暗黑/明亮主题切换
- MDX 博客支持
- RSS 订阅
- SEO 优化

## 开发

```bash
# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build

# 启动生产服务器
pnpm start
```

## 技术栈

- Next.js
- React
- TypeScript
- Tailwind CSS
- MDX
