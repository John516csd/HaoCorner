Hi, I'm Johnny - 文字效果演示（真正的Outline效果）

方法一：CSS 多重阴影
Hi, I'm Johnny
text-shadow: /* 白色描边 - 8个方向 */ -3px -3px 0 #fff, -3px 0px 0 #fff, -3px 3px 0 #fff, 0px -3px 0 #fff, 0px 3px 0 #fff, 3px -3px 0 #fff, 3px 0px 0 #fff, 3px 3px 0 #fff, /* 更多方向以实现圆润效果 */ -2px -2px 0 #fff, -2px 2px 0 #fff, 2px -2px 0 #fff, 2px 2px 0 #fff, -4px 0px 0 #fff, 4px 0px 0 #fff, 0px -4px 0 #fff, 0px 4px 0 #fff, /* 半透明阴影 */ 6px 6px 12px rgba(0, 0, 0, 0.3), 8px 8px 24px rgba(0, 0, 0, 0.2);
方法二：CSS Webkit描边
Hi, I'm Johnny
-webkit-text-stroke: 3px #fff; filter: drop-shadow(6px 6px 12px rgba(0, 0, 0, 0.3)) drop-shadow(8px 8px 24px rgba(0, 0, 0, 0.2));
方法三：SVG 真正的Outline（不侵蚀文字）
<text fill="none" stroke="#fff" stroke-width="12" stroke-linejoin="round" stroke-linecap="round" filter="url(#shadow)"> Hi, I'm Johnny </text> <text fill="#000" stroke="none"> Hi, I'm Johnny </text>
方法四：SVG 多层描边（更精细控制）
<text fill="none" stroke="#fff" stroke-width="14">...</text> <text fill="none" stroke="#fff" stroke-width="10">...</text> <text fill="none" stroke="#fff" stroke-width="6">...</text> <text fill="#000" stroke="none">Hi, I'm Johnny</text>
