# Eason Hero 素材与构图研究

当前阶段：素材准备与首屏构图。没有修改页面代码，没有确定全站配色。

## 文件

- `source-my-happy-days.png`：用户提供的原始封面，1200 × 1200，原样保留。
- `eason-cutout.png`：正式透明素材，1200 × 1200，RGBA PNG，保留原图坐标。
- `eason-cutout-web.webp`：裁去多余透明空白并缩小的展示用版本。经过有损压缩，后续精修应使用 PNG。
- `eason-alpha-mask.png`：透明度蒙版，白色为人物，黑色为透明背景。
- `clothing-repair-mask.png`：衣服修补范围，白色表示完全使用修补纹理，灰色表示过渡。
- `cutout-background-check.jpg`：同一张透明素材在浅色和深色背景上的检查图。
- `hero-composition.png`、`hero-composition.jpg`：首屏静态构图示意，1440 × 900；颜色仅用于灰阶构图。
- `asset-checks.json`：透明度和原图像素对比结果。

## 图像处理

使用本机 Apple Vision 生成人物蒙版，清理轮廓并填实人物内部。原图上方的头发、脸部和领口 RGB 像素保持原样，没有使用生成式重绘。

原封面的文字覆盖左侧衣服，并遮住部分衣服外轮廓。该区域使用同一张照片里未被遮挡的衣料取样，保留横向褶皱后进行局部映射与过渡；遮住的轮廓根据上下可见边界重建。因此，这部分是修补结果，不能视为找回了原本不可见的细节。修补区域主要位于 y=623..1169、x<650。

保留照片原有颗粒和清晰度，没有补画全身，也没有延展原图右侧和底部裁切。后续构图应让这两条裁切边贴近页面边缘。

PNG 实测存在真正的 Alpha 通道：透明度范围 0–255；头部检查框 (430,60)–(830,622) 内的 RGB 改动像素为 0。浅色、深色背景检查图已人工查看。

## Hero 构图建议

- 左侧放一条共鸣文案：「有些歌，一直陪着我们。」
- 右侧放人物，保留自然照片质感。
- 主入口「挑一张专辑」进入后续 3D 唱片架；次入口「读读我们的故事」连接歌迷分享。
- 顶部只保留姓名/站点标识和简短导航。
- 底部露出下一节唱片书脊，引导继续滚动。示意中的封面经过灰阶处理，仅用于观察形态；不是建议改变正式专辑封面的颜色。
- 中文使用清晰的无衬线中黑字重，英文姓名使用窄体。示意图以苹方与 Arial Narrow 排版，最终字体仍可调整。

下一步可以讨论人物比例、标题措辞、文字与照片的距离。当前没有锁定最终配色，也没有实现滚动或点击交互。
