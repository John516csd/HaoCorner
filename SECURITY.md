# Security Policy

## Reporting A Vulnerability

Please do not open a public issue for security-sensitive reports.

Send details to <yanchenhao57@gmail.com>, including:

- affected route, component, or dependency
- steps to reproduce
- expected impact
- any relevant logs, screenshots, or proof of concept

I will review the report and follow up as soon as I can.

## Scope

This is a personal website. The local content manager and its API are intended for local development and are disabled in production.
